## Descripción
Este proyecto fue desarrollado como parte del Trabajo Práctico de Organización Empresarial de la UTN.

El objetivo es analizar resultados deportivos utilizando Python, Git, GitHub y Jira para aplicar conceptos de:
- control de versiones
- trabajo colaborativo
- trazabilidad
- organización de proyectos

El sistema permite:
- calcular partidos ganados por equipo
- generar tabla de posiciones
- calcular promedio de goles
- generar gráficos comparativos de rendimiento
